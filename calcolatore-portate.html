A11004 (aspirazione 11014 A/B)

Vaschetta a destra delle membrane: riceve gli scarichi in parallelo da A–G. Da qui aspirano 11014 A/B. Membrane in servizio A–G; H fuori uso.

Start 80% = pompa in marcia. Stop 77% = pompa si ferma (basso livello).

Gestione pompe — Membrane MBR

Livello comune vaschette A–G. Start/stop svuotamento comandano tutte le membrane (oltre al ciclo lavoro/pausa).

A ≤ stop (77%) tutte le membrane si fermano. A ≥ start (85%) ripartono e riprendono il ciclo lavoro/pausa da dove si erano interrotte.

MP 11036 A/B riempiono le membrane fino a stop (92%), poi si fermano. Ripartono solo quando il livello MBR scende a start (85%). Servono anche A10611 OK (start/stop svuotamento proprio serbatoio).

Gestione — TK 11007 permeato

Serbatoio permeato sotto le membrane. Stop riempimento ferma tutte le membrane; a start riempimento ripartono (se anche MBR livello OK).

A ≥ stop (97%) membrane FERME. A ≤ start (90%) ripartono. Livello iniziale tipico 91%.

Gestione — TK 11021 permeato UF

Serbatoio permeato ultrafiltrazione (momentaneo). Start/stop riempimento sul livello UF.

A ≥ stop (97%) riempimento UF bloccato. A ≤ start (80%) riparte. Livello iniziale 91%.
